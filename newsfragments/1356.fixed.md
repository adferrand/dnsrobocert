Remove temporary configuration file in favour of using primary configuration file. Resolves issues with hooks used within a docker container or other short running process.

**Note:** existing failures with hooks due to missing configuration files will not be fixed automatically. Hooks will need to be manually updated in the `/etc/letsencrypt/renewal/<domain>.conf` file:

Configuration using temporary files:

```sh
manual_auth_hook = '/usr/local/bin/python3 -m dnsrobocert.core.hooks -t auth -c "/tmp/<random directory>/dnsrobocert-runtime.yml" -l "<domain>"'
manual_cleanup_hook = '/usr/local/bin/python3 -m dnsrobocert.core.hooks -t cleanup -c "/tmp/<random directory>/dnsrobocert-runtime.yml" -l "<domain>"'
renew_hook = '/usr/local/bin/python3 -m dnsrobocert.core.hooks -t deploy -c "/tmp/<random directory>/dnsrobocert-runtime.yml" -l "<domain>"'
```

Should be updated to:

```sh
manual_auth_hook = '/usr/local/bin/python3 -m dnsrobocert.core.hooks -t auth -c "/etc/dnsrobocert/config.yml" -l "<domain>"'
manual_cleanup_hook = '/usr/local/bin/python3 -m dnsrobocert.core.hooks -t cleanup -c "/etc/dnsrobocert/config.yml" -l "<domain>"'
renew_hook = '/usr/local/bin/python3 -m dnsrobocert.core.hooks -t deploy -c "/etc/dnsrobocert/config.yml" -l "<domain>"'
```

Alternatively remove these lines entirely and they will be replaced next time the certificate is updated.
